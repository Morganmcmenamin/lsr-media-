# LSR Media — Residential Pricing Reference

> Source of truth for the booking engine lives in `js/booking.js` (`services` + `bundlePrices`).
> This file is a human-readable mirror — keep them in sync when prices change.
> All prices NZD. A **+$50 large-property surcharge** applies on top of any price below.

## Savings logic

- **Standard bundles:** save **$50 per extra service** → $50 / $100 / $150 / $200
- **Bundles containing both Floor Plan + Virtual Tour (⭐):** start at **$195** off, then +$50 per extra service → $195 / $245 / $295 / $345
